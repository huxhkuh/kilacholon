# מיכלכלה

מיכלכלה היא אנציקלופדיה עברית ללימוד מושגים בשוק ההון, חיסכון ופנסיה, המותאמת לקריאה מימין לשמאל. השם משלב בין "מכללה" ל"כלכלה", והכותרת המסבירה באתר מחדדת מיד שמדובר בלימוד כלכלה ושוק ההון. האתר בנוי ב-React וב-Vite ומשתמש ב-Supabase לצורכי הרשמה, דיונים ותהליך אישור עריכות.

## הרצה מקומית

```sh
npm install
npm run dev
```

יש ליצור קובץ `.env.local` עם פרטי פרויקט Supabase:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-anon-key
```

## תהליך תוכן

1. תוכן בסיסי נשמר ב-`src/data/content.ts`.
2. משתמש מחובר יכול להגיש ערך חדש או תיקון. ההגשה נשמרת כגרסה ממתינה בלבד.
3. עורך או מנהל בודק הגשות במסך `/admin/revisions`.
4. לאחר אישור, הגרסה המאושרת האחרונה מוצגת בדפי הערכים, החיפוש, המילון והקטגוריות.

הצטרפות לכתיבה היא עצמאית: משתמש יכול להיכנס באמצעות קישור חד-פעמי ומאומת שנשלח לאימייל, ללא המתנה למנהל. תרומה מאושרת אחת מעניקה דרגת `new_writer`, ועשר תרומות מאושרות מעניקות `veteran_writer`. רק תפקידי `editor` או `admin`, שניתנים בנפרד, רשאים לאשר ולפרסם תוכן.

מדיניות RLS ב-Supabase היא חלק ממנגנון האבטחה: משתמש רגיל אינו יכול לפרסם עריכה בעצמו, לשנות את מונה התרומות המאושרות שלו או לקרוא תפקידים של משתמשים אחרים. יש להחיל את המיגרציות בתיקיית `supabase/migrations` בפרויקט Supabase לפני שימוש בתהליך האישור.

## פריסה מ-GitHub

המאגר כולל workflow שמפרסם את האתר ל-GitHub Pages אחרי כל מיזוג ל-`main`. בפעם הראשונה יש לבחור ב-GitHub תחת `Settings > Pages > Source` את האפשרות `GitHub Actions`. כתובת האתר תהיה:

```text
https://huxhkuh.github.io/kilacholon/
```

כדי שכניסה בקישור למייל תפעל בגרסה הציבורית, יש להוסיף ב-Supabase Auth את `https://huxhkuh.github.io/kilacholon/**` לרשימת כתובות ההפניה המורשות.

## אחריות תוכן

התוכן באתר נועד ללימוד ולמידע כללי בלבד, ואינו מהווה ייעוץ השקעות. לפני פרסום תוכן פיננסי יש לאמת נתונים מול מקורות רשמיים ולציין תאריך בדיקה ומקורות בתוך הערך.
