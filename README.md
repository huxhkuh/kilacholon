# מיכלכלה

מיכלכלה היא אנציקלופדיה עברית לכלכלה, שוק ההון וחיי היום־יום, המותאמת לקריאה מימין לשמאל. המאגר כולל 623 ערכים: 543 ערכים מלאים ו־80 קצרמרים. ההרחבה מוסיפה 500 ערכים מלאים ו־50 קצרמרים ל־73 הערכים המקוריים, שגם תוכנם שופר. האתר בנוי ב־React וב־Vite ומשתמש ב־Supabase לצורכי הרשמה, דיונים ותהליך אישור עריכות.

חיפוש בטקסט המלא תומך בניקוד עברי, שמות חלופיים, קטגוריות, רמות וסוגי ערכים. אפשר לשמור רשימת קריאה מקומית, להגדיל את טקסט המאמר, להדפיס, לעבור בין ערכים קשורים ולכתוב טיוטות שנשמרות אוטומטית בדפדפן. גופני Assistant ו־Frank Ruhl Libre מוגשים מהאתר עצמו עם רישיונותיהם.

## הרצה מקומית

```sh
npm ci
npm run dev
```

נדרש Node.js 22.18 ומעלה; הבדיקות והפריסה משתמשות ב־Node.js 24. יש ליצור קובץ `.env.local` עם פרטי פרויקט Supabase:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-anon-key
```

## תהליך תוכן

1. תוכן בסיסי נשמר ב־`src/data/content.ts`, תיקוני הערכים המקוריים ב־`seed-enhancements.ts` וב־`stub-enhancements.ts`, וההרחבה בחמשת קובצי JSON תחת `src/data/expansion/`. `catalog.ts` מחבר אותם למאגר אחד.
2. משתמש מחובר יכול להגיש ערך חדש או תיקון. ההגשה נשמרת כגרסה ממתינה בלבד.
3. עורך או מנהל בודק הגשות במסך `/admin/revisions`.
4. לאחר אישור, הגרסה המאושרת האחרונה מוצגת בדפי הערכים, החיפוש, המילון והקטגוריות.

הצטרפות לכתיבה היא עצמאית: משתמש יכול להיכנס באמצעות קישור חד-פעמי ומאומת שנשלח לאימייל, ללא המתנה למנהל. תרומה מאושרת אחת מעניקה דרגת `new_writer`, ועשר תרומות מאושרות מעניקות `veteran_writer`. רק תפקידי `editor` או `admin`, שניתנים בנפרד, רשאים לאשר ולפרסם תוכן.

מדיניות RLS ב-Supabase היא חלק ממנגנון האבטחה: משתמש רגיל אינו יכול לפרסם עריכה בעצמו, לשנות את מונה התרומות המאושרות שלו או לקרוא תפקידים של משתמשים אחרים. יש להחיל את המיגרציות בתיקיית `supabase/migrations` בפרויקט Supabase לפני שימוש בתהליך האישור.

## בדיקות ובנייה

```sh
npm run lint
npm run typecheck
npm test
npm run test:database
npm audit
npm run build
```

הבדיקות בודקות גם את כמות הערכים, עומק התוכן, דוגמאות ושאלות, ייחודיות שמות ונתיבים, תקינות קישורים פנימיים ומקורות, שמירת טיוטות, טעינת הרשאות, בטיחות הצגת הטקסט ודירוג חיפוש. הבנייה מפיקה HTML קריא לכל ערך וקטגוריה, `sitemap.xml` ו־`robots.txt`. התוכן הסטטי מגיע מהמאגר; עריכות קהילתיות מאושרות נטענות לאחר הפעלת JavaScript.

## פריסה מ-GitHub

המאגר כולל workflow שמפרסם את האתר ל-GitHub Pages אחרי כל מיזוג ל-`main`. בפעם הראשונה יש לבחור ב-GitHub תחת `Settings > Pages > Source` את האפשרות `GitHub Actions`. כתובת האתר תהיה:

```text
https://huxhkuh.github.io/kilacholon/
```

כדי שכניסה בקישור למייל תפעל בגרסה הציבורית, יש להוסיף ב-Supabase Auth את `https://huxhkuh.github.io/kilacholon/**` לרשימת כתובות ההפניה המורשות.

בפריסה לכתובת אחרת יש להגדיר גם `VITE_BASE_PATH` וגם `VITE_SITE_URL` לפני הבנייה כדי לשמור על קישורים קנוניים ומפת אתר נכונים.

### עדכון מסד הנתונים

הקובץ `supabase/migrations/20260916090000_revision_review_guard.sql` מחזק את כללי ההגשה והבדיקה: הגשות חדשות חייבות להיות במצב המתנה, שיוך המחבר נשמר, ורק עורך רשאי לשנות החלטת פרסום. יש להחילו על פרויקט Supabase דרך מסלול המיגרציות הרגיל. פריסת GitHub Pages אינה מחילה מיגרציות Supabase. בדיקת ההרשאות בדפדפן אינה מחליפה את מדיניות מסד הנתונים.

בדיקת `test:database` מפעילה PostgreSQL באמצעות PGlite בסביבה מקומית זמנית ובודקת הגשה, אישור, שיוך מחבר ופרטי עורך. היא אינה משנה את Supabase החי.

בדיקות מקומיות של ממשק העריכה משתמשות באורח ובטיוטות מקומיות בלבד. בדיקת התחברות, פרסום, דיון וניהול תפקידים מקצה לקצה דורשת חשבונות בדיקה מורשים וסביבת Supabase שבה המיגרציות הוחלו.

## תשתית עצמאית

האתר אינו תלוי ב-Lovable לצורך פיתוח, בנייה או פריסה. הקוד נבנה עם Vite ו-`npm`, נפרס מ-GitHub Actions ל-GitHub Pages, ומשתמש ב-Supabase לאימות, אחסון ותוכן שיתופי. `package-lock.json` הוא קובץ הנעילה היחיד של ההתקנה.

## אחריות תוכן

התוכן באתר נועד ללימוד ולמידע כללי בלבד, ואינו מהווה ייעוץ השקעות. לפני פרסום תוכן פיננסי יש לאמת נתונים מול מקורות רשמיים ולציין תאריך בדיקה ומקורות בתוך הערך.

ערך חדש כולל הגדרה, לפחות שלושה פרקי הסבר, דוגמה, שימושים ומגבלות, שתי שאלות ותשובות ומקורות להרחבה. קצרמר מכיל מבוא מועיל ומפרט מה עוד חסר בו; הוא אינו נספר כערך מלא. בדיקת אורך ומבנה היא סף טכני ואינה תחליף לבדיקת דיוק מקצועית. מקורות זרים משמשים להסבר עקרונות ולא לקביעת זכויות או חובות בישראל; שיעורי מס, תקרות וזכאויות נבדקים מול הרשות הרלוונטית בעת שימוש מעשי.
