## קוד ובנייה

- התקנה נקייה באמצעות `npm ci`: עברה.
- `npm run typecheck`: עבר.
- `npm run lint`: אפס שגיאות; 10 אזהרות Fast Refresh בקבצים שמייצאים רכיבי React יחד עם ערכים נוספים.
- `npm test`: 26 בדיקות בתשעה קבצים עברו.
- `npm run test:database`: שש בדיקות התנהגות עברו ב־PostgreSQL מקומי באמצעות PGlite. נבדקו גם החלפת מדיניות קיימת והרצה חוזרת של המיגרציה.
- `npm audit --audit-level=low`: אפס חולשות ידועות בתלויות בזמן הבדיקה.
- בניית ייצור עם `VITE_BASE_PATH=/kilacholon/`: עברה; נוצרו 623 דפי ערכים קריאים, 19 דפי קטגוריות ומפת אתר. אין אזהרת קובצי JavaScript גדולים מסף 500kB.
